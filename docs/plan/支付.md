### 1.5 📌 个人开发者资质说明与 4 大最佳替代方案 (重要)

> [!IMPORTANT]
> **官方资质政策硬性要求**：
> - **微信支付 (WeChat Pay)**：官方**不支持纯个人身份证**直接申请 API 商户号。必须具备 **营业执照**（个体工商户或企业公司）。
> - **支付宝 (Alipay)**：
>   - 电脑网站/手机网站支付：官方要求必须有营业执照。
>   - **当面付（预下单二维码）**：支付宝官方**支持个人开发者免营业执照申请**（只需提交门店照片/手持身份证/挂靠证明，即可开启个人扫码收款，单笔限额 1000 元/日）。
>   - **支付宝沙箱环境 (Sandbox)**：100% 对个人开发者免费开放，无需任何资质，秒开密钥用于本地及开发联调！

针对个人开发者在没有公司或营业执照时，推荐以下 **4 种落地与商业化变现方案**：

#### 方案一：注册“个体工商户”（⭐ 最推荐、合法合规、成本极低）
- **办理途径**：现在全国多地（如浙江、海南、广东、贵州等）均支持**零成本线上极速办理个体工商户营业执照**（支持电子挂靠地址，费用 0~200 元）。
- **优势**：拿到个体户执照后，可 **100% 官方直接申请微信支付 + 支付宝官方当面付/电脑支付**，资金直接结算到个人银行卡，费率仅 0.6%，完全合规无封号风险。

#### 方案二：接入合规个人聚合支付平台（免执照、极速上线）
- **推荐服务商**：
  - **虎皮椒 (XunhuPay)**：专为个人开发者提供的免执照微信/支付宝 API 接口服务，提供 SDK 和回调 Webhook，资金按日自动结算。
  - **PayPapi / Payjs**：支持个人开发者的签约支付服务商。
  - **Stripe (海外版)**：如果有香港个人银行卡或海外账户，可直接注册 Stripe 个人版，支持全球信用卡/微信/支付宝收款。
- **优势**：无需营业执照，15 分钟内完成 API 密钥配置并上线体验。

#### 方案三：使用创作者平台代结算 API（面包多 / 爱发电）
- **适用场景**：通过 **面包多 API (mianbaoduo.com)** 或 **爱发电 API (afdian.net)** 发起赞助/购买算力包。
- **流程**：用户在前端点击购买跳转至面包多/爱发电商品页面完成微信/支付宝付款，平台 Webhook 收到回调后自动在 Shopro AI 中为用户开通积分，资金由平台代扣税后结算至个人微信/支付宝。

#### 方案四：开发测试阶段使用“支付宝沙箱” + “个人收款码人工审核”
- **开发阶段**：使用 **支付宝沙箱环境**（使用 `alipay-sdk` 配合沙箱 `AppId` 和测试钱包 App）完成全部前端和后端 Edge Functions 流程联调。
- **种子用户上线过渡**：前端展示个人微信/支付宝收款码，用户转账后上传截图，后台或客服在 Dashboard 一键手动为用户充值积分。

## 📌 2. 前置准备与商户账号配置教程

### 2.1 微信支付 (WeChat Pay v3) 配置步骤

1. **注册微信支付商户号**：
   - 访问 [微信支付商家助手](https://pay.weixin.qq.com/) 注册企业/个体户商户号，获取 **`MERCHANT_ID` (mchid)**。
   - 绑定对应的微信公众号或小程序/开放平台 App，获取 **`MERCHANT_APP_ID` (appid)**。

2. **生成并下载 APIv3 证书与私钥**：
   - 进入【账户中心】➔【API安全】➔【申请 API 证书】。
   - 导出的 `apiclient_key.pem` 内容即为 **`MCH_PRIVATE_KEY`**。
   - 记录证书序列号，即为 **`MCH_CERT_SERIAL_NO`**。

3. **设置 APIv3 密钥**：
   - 在【API安全】设置 32 位字符的 APIv3 密钥，即为 **`MCH_API_V3_KEY`**。

4. **获取微信支付公钥**：
   - 记录微信支付公钥 ID **`WECHAT_PAY_PUBLIC_KEY_ID`** 与内容 **`WECHAT_PAY_PUBLIC_KEY`**。

5. **配置 Supabase 环境变量**：
   ```bash
   supabase secrets set MERCHANT_ID="160xxxxxxx"
   supabase secrets set MERCHANT_APP_ID="wx1234567890abcdef"
   supabase secrets set MCH_CERT_SERIAL_NO="3C17XXXXXXXXXXXXXXXX"
   supabase secrets set MCH_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIE..."
   supabase secrets set WECHAT_PAY_PUBLIC_KEY_ID="PUB_KEY_ID_xxxx"
   supabase secrets set WECHAT_PAY_PUBLIC_KEY="-----BEGIN PUBLIC KEY-----\nMIIB..."
   supabase secrets set MCH_API_V3_KEY="your_32_bit_apiv3_secret_key_here"
   ```

---

### 2.2 支付宝 (Alipay v2) 配置步骤

1. **注册支付宝开放平台**：
   - 访问 [支付宝开放平台](https://open.alipay.com/) 创建“自研应用”或“网页&移动应用”，获取 **`ALIPAY_APP_ID`**。

2. **生成 RSA2 密钥对**：
   - 下载使用“支付宝密钥生成器”，选择 **RSA2 (SHA256withRSA)** 密钥格式。
   - 生成【应用私钥】(`PKCS8` 格式)，填入 Supabase 环境变量 **`ALIPAY_PRIVATE_KEY`**。
   - 将【应用公钥】上传至支付宝开放平台后台。

3. **获取支付宝公钥**：
   - 上传应用公钥后，支付宝会生成对应的 **【支付宝公钥】** (`ALIPAY_PUBLIC_KEY`)，复制并填入环境变量。

4. **开通支付产品**：
   - 在应用详情中勾选开通 **【当面付】**（生成 Native 扫码支付二维码）或 **【电脑网站支付】**（PC端页面跳转）。

5. **配置 Supabase 环境变量**：
   ```bash
   supabase secrets set ALIPAY_APP_ID="2021000000000000"
   supabase secrets set ALIPAY_PRIVATE_KEY="MIIEvgIBADANBgkqhkiG9w0BAQEFAASCBKgwggSkAgEAAoIBAQC..."
   supabase secrets set ALIPAY_PUBLIC_KEY="MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQE..."
   # 生产环境网关：https://openapi.alipay.com/gateway.do
   # 沙箱环境网关：https://openapi-sandbox.dl.alipaydev.com/gateway.do
   supabase secrets set ALIPAY_GATEWAY="https://openapi.alipay.com/gateway.do"
   ```

## 📌 3. 数据库结构与防并发原子锁设计

在 Supabase 中使用 Migration 脚本升级 `orders` 表，并创建事务级打账 RPC 函数：

### 3.1 订单表 `orders` Migration 升级脚本

```sql
-- migration: 00020_add_alipay_and_payment_rpc.sql

-- 1. 为 orders 表补充支付类型与第三方流水号
ALTER TABLE public.orders 
ADD COLUMN IF NOT EXISTS pay_type VARCHAR(20) DEFAULT 'wechat', -- 'wechat' | 'alipay'
ADD COLUMN IF NOT EXISTS trade_no VARCHAR(100),                 -- 第三方支付交易号
ADD COLUMN IF NOT EXISTS alipay_pay_url TEXT;                   -- 支付宝支付 URL 或 Form 页面表单

-- 2. 添加索引
CREATE INDEX IF NOT EXISTS idx_orders_status_pay_type ON public.orders(status, pay_type);
CREATE INDEX IF NOT EXISTS idx_orders_trade_no ON public.orders(trade_no);

-- 3. 创建防重复扣款的原子打账 RPC 存储过程
CREATE OR REPLACE FUNCTION public.handle_payment_success(
  p_order_no TEXT,
  p_trade_no TEXT
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
DECLARE
  v_order RECORD;
  v_plan RECORD;
  v_current_credits INT := 0;
  v_new_credits INT := 0;
  v_expires_at TIMESTAMPTZ;
BEGIN
  -- 排他锁（悲观锁）：锁住订单行，防止并发 Webhook 撞车打账
  SELECT * INTO v_order
  FROM public.orders
  WHERE order_no = p_order_no
  FOR UPDATE;

  IF NOT FOUND THEN
    RETURN jsonb_build_object('success', false, 'message', '订单不存在');
  END IF;

  -- 幂等校验：如果订单已经被置为 paid，直接返回成功，不重复加账
  IF v_order.status = 'paid' THEN
    RETURN jsonb_build_object('success', true, 'message', '订单已处理过，无需重复加费');
  END IF;

  -- 更新订单状态为 paid
  UPDATE public.orders
  SET 
    status = 'paid',
    trade_no = p_trade_no,
    paid_at = NOW(),
    updated_at = NOW()
  WHERE order_no = p_order_no;

  -- 查询对应套餐详情
  SELECT * INTO v_plan
  FROM public.plans
  WHERE id = v_order.plan_id;

  IF NOT FOUND THEN
    RETURN jsonb_build_object('success', false, 'message', '关联套餐不存在');
  END IF;

  -- 锁定并查询用户当前配额记录
  SELECT credits_total INTO v_current_credits
  FROM public.user_plans
  WHERE user_id = v_order.user_id
  FOR UPDATE;

  IF v_plan.level < 0 THEN
    -- 【加油包逻辑】：只累加积分，不动原套餐过期时间
    v_new_credits := COALESCE(v_current_credits, 0) + v_plan.credits;
    
    INSERT INTO public.user_plans (user_id, credits_total, status, updated_at)
    VALUES (v_order.user_id, v_new_credits, 'active', NOW())
    ON CONFLICT (user_id) DO UPDATE
    SET 
      credits_total = v_new_credits,
      updated_at = NOW();

    -- 写入积分日志
    INSERT INTO public.credit_logs (user_id, action, amount, balance_after, description)
    VALUES (v_order.user_id, 'booster_purchase', v_plan.credits, v_new_credits, '购买算力加油包增加积分');

  ELSE
    -- 【SaaS 套餐升级/续费逻辑】：更新套餐并重置积分与过期时间（1个月后）
    v_new_credits := v_plan.credits;
    v_expires_at := NOW() + INTERVAL '1 month';

    INSERT INTO public.user_plans (user_id, plan_id, credits_total, credits_used, expires_at, status, updated_at)
    VALUES (v_order.user_id, v_plan.id, v_new_credits, 0, v_expires_at, 'active', NOW())
    ON CONFLICT (user_id) DO UPDATE
    SET 
      plan_id = v_plan.id,
      credits_total = v_new_credits,
      credits_used = 0,
      expires_at = v_expires_at,
      status = 'active',
      updated_at = NOW();

    -- 写入积分日志
    INSERT INTO public.credit_logs (user_id, action, amount, balance_after, description)
    VALUES (v_order.user_id, 'plan_purchase', v_plan.credits, v_new_credits, '开通/升级会员套餐');
  END IF;

  RETURN jsonb_build_object('success', true, 'message', '订单支付成功，资产入账完毕');
END;
$$;
```

## 📌 4. Supabase Edge Functions 双支付后端实现

### 4.1 统一创建支付订单 Edge Function (`create-payment-order/index.ts`)

在微服务中集成 **支付宝 Precreate/PagePay** 和 **微信 Native** 双入口：

```typescript
// supabase/functions/create-payment-order/index.ts
import { createClient } from 'npm:@supabase/supabase-js@2';
import { Wechatpay } from 'npm:wechatpay-axios-plugin';
import AlipaySdk from 'npm:alipay-sdk';
import ShortUniqueId from 'npm:short-unique-id';

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
  'Access-Control-Allow-Methods': 'POST, OPTIONS',
};

function ok(data: unknown) {
  return new Response(JSON.stringify({ code: 0, message: 'success', data }), {
    headers: { ...corsHeaders, 'Content-Type': 'application/json' },
  });
}
function err(message: string, status = 400) {
  return new Response(JSON.stringify({ code: 1, message, data: null }), {
    status,
    headers: { ...corsHeaders, 'Content-Type': 'application/json' },
  });
}

function generateOrderNo(): string {
  const uid = new ShortUniqueId({ length: 8 });
  const yymmdd = new Date().toISOString().slice(2, 10).replace(/-/g, '');
  return `ORD-${yymmdd}-${uid.rnd()}`;
}

// 1. 创建微信支付 Native 二维码
async function createWechatPayUrl(outTradeNo: string, amount: number, notifyUrl: string) {
  const wxpay = new Wechatpay({
    mchid: Deno.env.get('MERCHANT_ID')!,
    serial: Deno.env.get('MCH_CERT_SERIAL_NO')!,
    privateKey: Deno.env.get('MCH_PRIVATE_KEY')!,
    certs: { [Deno.env.get('WECHAT_PAY_PUBLIC_KEY_ID')!]: Deno.env.get('WECHAT_PAY_PUBLIC_KEY')! },
  });
  const res = await wxpay.v3.pay.transactions.native.post({
    mchid: Deno.env.get('MERCHANT_ID')!,
    out_trade_no: outTradeNo,
    appid: Deno.env.get('MERCHANT_APP_ID')!,
    description: 'Shopro AI - 算力套餐升级',
    notify_url: notifyUrl,
    amount: { total: Math.round(amount * 100) },
  }, { headers: { 'Wechatpay-Serial': Deno.env.get('WECHAT_PAY_PUBLIC_KEY_ID')! } });
  
  if (res.data.code_url) return { success: true, url: res.data.code_url };
  return { success: false, error: res.data.message || JSON.stringify(res.data) };
}

// 2. 创建支付宝 Precreate (当面付二维码) / PagePay
async function createAlipayUrl(outTradeNo: string, amount: number, notifyUrl: string) {
  const alipaySdk = new AlipaySdk({
    appId: Deno.env.get('ALIPAY_APP_ID')!,
    privateKey: Deno.env.get('ALIPAY_PRIVATE_KEY')!,
    alipayPublicKey: Deno.env.get('ALIPAY_PUBLIC_KEY')!,
    gateway: Deno.env.get('ALIPAY_GATEWAY') || 'https://openapi.alipay.com/gateway.do',
  });

  // 调用 alipay.trade.precreate 接口获取二维码链接
  const result = await alipaySdk.exec('alipay.trade.precreate', {
    notify_url: notifyUrl,
    bizContent: {
      out_trade_no: outTradeNo,
      total_amount: amount.toFixed(2),
      subject: 'Shopro AI - 电商AIGC带货视频套餐升级',
    },
  });

  if (result.code === '10000' && result.qrCode) {
    return { success: true, url: result.qrCode };
  }
  return { success: false, error: result.subMsg || result.msg };
}

Deno.serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const supabase = createClient(
    Deno.env.get('SUPABASE_URL') ?? '',
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY') ?? '',
  );

  try {
    const authHeader = req.headers.get('Authorization');
    if (!authHeader) return err('未授权', 401);
    const { data: { user }, error: authErr } = await createClient(
      Deno.env.get('SUPABASE_URL') ?? '',
      Deno.env.get('SUPABASE_ANON_KEY') ?? '',
    ).auth.getUser(authHeader.replace('Bearer ', ''));
    if (authErr || !user) return err('认证失败', 401);

    const { plan_id, pay_type = 'wechat' } = await req.json() as { plan_id: string; pay_type?: 'wechat' | 'alipay' };
    if (!plan_id) return err('缺少 plan_id');

    const { data: plan } = await supabase.from('plans').select('*').eq('id', plan_id).maybeSingle();
    if (!plan) return err('套餐不存在');
    if (plan.price === 0) return err('免费套餐无需支付');

    const orderNo = generateOrderNo();

    if (pay_type === 'alipay') {
      const notifyUrl = `${Deno.env.get('SUPABASE_URL')}/functions/v1/alipay-payment-webhook`;
      const payRes = await createAlipayUrl(orderNo, plan.price, notifyUrl);
      if (!payRes.success) return err(`支付宝创建失败：${payRes.error}`, 500);

      const { data: order } = await supabase.from('orders').insert({
        order_no: orderNo,
        user_id: user.id,
        plan_id: plan.id,
        status: 'pending',
        pay_type: 'alipay',
        total_amount: plan.price,
        alipay_pay_url: payRes.url,
      }).select().maybeSingle();

      return ok({
        order_no: orderNo,
        pay_type: 'alipay',
        pay_url: payRes.url,
        plan_name: plan.name,
        amount: plan.price,
      });
    } else {
      const notifyUrl = `${Deno.env.get('SUPABASE_URL')}/functions/v1/wechat-payment-webhook`;
      const payRes = await createWechatPayUrl(orderNo, plan.price, notifyUrl);
      if (!payRes.success) return err(`微信支付创建失败：${payRes.error}`, 500);

      const { data: order } = await supabase.from('orders').insert({
        order_no: orderNo,
        user_id: user.id,
        plan_id: plan.id,
        status: 'pending',
        pay_type: 'wechat',
        total_amount: plan.price,
        wechat_pay_url: payRes.url,
      }).select().maybeSingle();

      return ok({
        order_no: orderNo,
        pay_type: 'wechat',
        wechat_pay_url: payRes.url,
        plan_name: plan.name,
        amount: plan.price,
      });
    }
  } catch (e) {
    return err(e instanceof Error ? e.message : '服务异常', 500);
  }
});
```

### 4.2 支付宝回调验签与原子打账 Edge Function (`alipay-payment-webhook/index.ts`)

```typescript
// supabase/functions/alipay-payment-webhook/index.ts
import { createClient } from 'npm:@supabase/supabase-js@2';
import AlipaySdk from 'npm:alipay-sdk';

Deno.serve(async (req) => {
  const supabase = createClient(
    Deno.env.get('SUPABASE_URL') ?? '',
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY') ?? '',
  );

  try {
    // 支付宝 Webhook 为 application/x-www-form-urlencoded
    const formData = await req.formData();
    const params: Record<string, string> = {};
    for (const [key, value] of formData.entries()) {
      params[key] = value.toString();
    }

    console.log('[Alipay Webhook Received]', params.out_trade_no, params.trade_status);

    const alipaySdk = new AlipaySdk({
      appId: Deno.env.get('ALIPAY_APP_ID')!,
      privateKey: Deno.env.get('ALIPAY_PRIVATE_KEY')!,
      alipayPublicKey: Deno.env.get('ALIPAY_PUBLIC_KEY')!,
    });

    // 1. RSA2 签名验签
    const isValid = alipaySdk.checkNotifySign(params);
    if (!isValid) {
      console.error('[Alipay Webhook] 验签失败！');
      return new Response('failure', { status: 400 });
    }

    // 2. 检验 trade_status 是否为 TRADE_SUCCESS 或 TRADE_FINISHED
    const tradeStatus = params.trade_status;
    if (tradeStatus !== 'TRADE_SUCCESS' && tradeStatus !== 'TRADE_FINISHED') {
      return new Response('success', { status: 200 });
    }

    const outTradeNo = params.out_trade_no;
    const tradeNo = params.trade_no;

    // 3. 调用 PostgreSQL RPC 原子存贮过程（防并发锁与打账）
    const { data: rpcRes, error: rpcErr } = await supabase.rpc('handle_payment_success', {
      p_order_no: outTradeNo,
      p_trade_no: tradeNo,
    });

    if (rpcErr) {
      console.error('[Alipay RPC Error]', rpcErr.message);
      return new Response('failure', { status: 500 });
    }

    console.log('[Alipay Success]', rpcRes);

    // 支付宝必须返回纯字符串 'success'
    return new Response('success', { status: 200, headers: { 'Content-Type': 'text/plain' } });
  } catch (e) {
    console.error('[Alipay Webhook Exception]', e);
    return new Response('failure', { status: 500 });
  }
});
```

## 📌 5. 前端收银台与 UI 对接步骤

在 `src/pages/CreditsPage.tsx` 中增加支付宝/微信双选项与自动轮询：

### 5.1 前端核心交互逻辑实现

```tsx
// src/components/PaymentModal.tsx
import React, { useState, useEffect } from 'react';
import { Dialog, DialogContent, DialogHeader, DialogTitle } from '@/components/ui/dialog';
import { Button } from '@/components/ui/button';
import QRCodeDataUrl from '@/components/ui/qrcodedataurl';
import { supabase } from '@/db/supabase';
import { toast } from 'sonner';
import { Loader2, CheckCircle2 } from 'lucide-react';

interface PaymentModalProps {
  open: boolean;
  onClose: () => void;
  plan: { id: string; name: string; price: number } | null;
  onSuccess: () => void;
}

export function PaymentModal({ open, onClose, plan, onSuccess }: PaymentModalProps) {
  const [payType, setPayType] = useState<'wechat' | 'alipay'>('wechat');
  const [loading, setLoading] = useState(false);
  const [payUrl, setPayUrl] = useState('');
  const [orderNo, setOrderNo] = useState('');
  const [paid, setPaid] = useState(false);

  // 创建订单
  const handleCreateOrder = async (selectedType: 'wechat' | 'alipay') => {
    if (!plan) return;
    setLoading(true);
    setPayUrl('');
    setPayType(selectedType);

    try {
      const { data: { session } } = await supabase.auth.getSession();
      if (!session) {
        toast.error('请先登录');
        return;
      }

      const { data, error } = await supabase.functions.invoke('create-payment-order', {
        body: { plan_id: plan.id, pay_type: selectedType },
        headers: { Authorization: `Bearer ${session.access_token}` },
      });

      if (error || data.code !== 0) {
        toast.error(data?.message || '创建订单失败');
        return;
      }

      setOrderNo(data.data.order_no);
      setPayUrl(data.data.pay_url || data.data.wechat_pay_url);
    } catch (e) {
      toast.error('创建订单发生异常');
    } finally {
      setLoading(false);
    }
  };

  // 监听 modal 打开时默认创建微信支付
  useEffect(() => {
    if (open && plan) {
      setPaid(false);
      handleCreateOrder('wechat');
    }
  }, [open, plan]);

  // 轮询订单状态 (每 2 秒查询一次)
  useEffect(() => {
    let timer: NodeJS.Timeout;
    if (open && orderNo && !paid) {
      timer = setInterval(async () => {
        const { data } = await supabase
          .from('orders')
          .select('status')
          .eq('order_no', orderNo)
          .maybeSingle();

        if (data?.status === 'paid') {
          setPaid(true);
          toast.success('支付成功！算力已实时到账');
          onSuccess();
          setTimeout(() => onClose(), 1500);
        }
      }, 2000);
    }
    return () => clearInterval(timer);
  }, [open, orderNo, paid]);

  return (
    <Dialog open={open} onOpenChange={onClose}>
      <DialogContent className="sm:max-w-md">
        <DialogHeader>
          <DialogTitle className="text-center text-xl font-bold">
            升级套餐：{plan?.name} (¥{plan?.price})
          </DialogTitle>
        </DialogHeader>

        {/* 支付方式切换卡片 */}
        <div className="grid grid-cols-2 gap-3 my-4">
          <Button
            variant={payType === 'wechat' ? 'default' : 'outline'}
            className={payType === 'wechat' ? 'bg-emerald-600 hover:bg-emerald-700 text-white' : ''}
            onClick={() => handleCreateOrder('wechat')}
          >
            💬 微信支付
          </Button>
          <Button
            variant={payType === 'alipay' ? 'default' : 'outline'}
            className={payType === 'alipay' ? 'bg-sky-600 hover:bg-sky-700 text-white' : ''}
            onClick={() => handleCreateOrder('alipay')}
          >
            🟦 支付宝支付
          </Button>
        </div>

        {/* 二维码展示区域 */}
        <div className="flex flex-col items-center justify-center p-6 border rounded-xl bg-muted/20">
          {loading ? (
            <div className="flex flex-col items-center gap-2 py-8">
              <Loader2 className="w-8 h-8 animate-spin text-primary" />
              <p className="text-sm text-muted-foreground">正在生成{payType === 'wechat' ? '微信' : '支付宝'}支付二维码...</p>
            </div>
          ) : paid ? (
            <div className="flex flex-col items-center gap-2 py-8 text-emerald-600">
              <CheckCircle2 className="w-12 h-12" />
              <p className="text-lg font-bold">支付成功！</p>
            </div>
          ) : payUrl ? (
            <div className="flex flex-col items-center gap-3">
              <div className="p-3 bg-white rounded-lg shadow-sm border">
                <QRCodeDataUrl text={payUrl} size={200} />
              </div>
              <p className="text-xs text-muted-foreground">
                请使用 {payType === 'wechat' ? '微信扫一扫' : '支付宝扫一扫'} 扫码完成支付
              </p>
            </div>
          ) : (
            <p className="text-sm text-destructive py-6">无法生成支付二维码，请重试</p>
          )}
        </div>
      </DialogContent>
    </Dialog>
  );
}
```

## 📌 7. 常见问题排查 (Troubleshooting)

1. **微信支付验签失败**：
   - 检查 `MCH_PRIVATE_KEY` 换行符是否被破坏（使用 `\n` 替代换行）。
   - 检查 `MCH_API_V3_KEY` 是否为 32 位精准字符串。
2. **支付宝回调重复入账**：
   - 确认使用了 SQL RPC 函数 `handle_payment_success` 内置的 `FOR UPDATE` 悲观锁与 `status = 'paid'` 幂等拦截。
3. **域名与 Webhook 穿透问题**：
   - 本地开发时，需使用 `ngrok http 54321` 将本地边缘函数映射为 HTTPS 公网域名，并填入商户后台 Webhook 校验。
