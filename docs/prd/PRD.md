## 1️⃣ 产品概述

### 📌 1.1 项目简介（名称 / 定位）

| 维度 | 说明 |
|---|---|
| **产品名称** | Shopro AI —— 电商 AIGC 带货视频创作系统 |
| **产品定位** | 面向抖音、TikTok、快手、小红书、Amazon、Shopee 等电商平台商家的**一站式短视频营销 SaaS 平台**，通过多模态大模型与全链路智能工作流，实现「商品输入 → 脚本生成 → 数字人合成 → 视频渲染 → 跨平台发布 → 数据回流」的商业闭环 |
| **产品口号** | 一人 + 浏览器，量产爆款带货短视频 |
| **架构形态** | 双端解耦：① **商家创作端**（React，C/B 端）② **厂商运营中台**（Vue + Element Plus，多租户 SaaS 运维） |
| **核心价值** | 将传统「文案 + 拍摄 + 剪辑 + 翻译 + 运营」五人工作流压缩为「一人 + AI」，单条视频综合成本降至不足 1 元 |

### 👥 1.2 用户与使用场景

| 用户角色 | 画像特征 | 典型使用场景 |
|---|---|---|
| 🏪 **中小电商商家** | 独立运营店铺、预算有限、无专业团队 | 大促期间需低成本快速量产大量带货短视频 |
| 🌍 **跨境电商卖家** | 面向 TikTok / Amazon / Shopee 海外市场 | 需一键生成多语种本地化数字人口播视频 |
| 🎬 **MCN 机构 / 代运营** | 同时服务多个品牌客户 | 需批量生产、团队协作与统一账号管理 |
| 📊 **品牌方市场部** | 关注投放 ROI 与创意测试 | 需快速 A/B 测试不同脚本 / 封面策略 |
| 🏢 **平台运营方（厂商端）** | SaaS 平台运维与风控团队 | 需算力调账、AI 任务追踪、内容风控与订单审计 |

### 💢 1.3 痛点与价值

| 用户痛点 | Shopro AI 解决方案 | 交付价值 |
|---|---|---|
| 😫 文案撰写难、不会写爆款脚本 | CoT 四层营销脚本生成（钩子 → 痛点 → 产品 → CTA） | 无需文案能力，量产高转化脚本 |
| 💸 数字人 / 外籍演员成本高 | AI 数字人克隆 + CosyVoice2 情感语音合成 | 免真人拍摄，成本降至 1 元级 |
| ✂️ 视频剪辑门槛高、耗时长 | 多轨道可视化 Canvas 分镜编辑器 | 拖拽式「拼积木」，免学习上手 |
| 🌐 多语言本地化差 | DeepSeek 智能翻译 + 情感配音，50+ 语种 | 快速出海，一键本地化 |
| 📤 跨平台发布繁琐 | 抖音 / TikTok / 小红书 / 快手 / B 站排期一键发布 | 统一分发，节省运营人力 |
| 📉 投放效果难预测 | ROI 预测 + A/B 测试 + 数据回流自调优 | 数据驱动，越用越聪明 |

### 🔍 1.4 竞品调研

| 竞品 | 优势 | 劣势 | 差异化机会 |
|---|---|---|---|
| **剪映专业版** | 工具成熟、上手简单 | AI 生成能力有限、数字人薄弱 | Shopro 主打「生成」而非「剪辑」 |
| **HeyGen** | 数字人效果优秀 | 价格昂贵、国内访问不稳定 | Shopro 性价比高、本土化服务好 |
| **Synthesia** | 企业级数字人服务 | 生成速度慢、定制能力弱 | Shopro 3-5 分钟极速出片 |
| **Runway** | 视频生成技术领先 | 非电商垂直、无营销闭环 | Shopro 深耕电商 + 营销学框架 |
| **即梦 AI** | 字节系、适配抖音 | 功能单一、跨平台能力弱 | Shopro 全平台 + 全链路闭环 |

> **🏆 Shopro AI 核心竞争优势**：① 电商垂直场景深耕；② 全链路商业闭环（不止生成，覆盖发布与数据回流）；③ 多语种出海能力；④ 极致性价比（单条 < 1 元）；⑤ 商家端 + 厂商端双端企业级架构。

## 5️⃣ 技术架构

### 🏗️ 5.1 整体分层架构（前后端分离）

| 层级 | 技术选型 | 说明 |
|---|---|---|
| 🎨 前端展示层（商家端） | **React 18.3.1 + TypeScript 5.7.2 + Vite** | 组件化 UI、强类型约束、极速热更新 |
| 🎨 前端展示层（厂商端） | **Vue 3.5.13 + TypeScript + Element Plus** | 企业级表格 / 表单 / 仪表盘运营后台 |
| 💅 样式与动效层 | TailwindCSS 3 + framer-motion + Radix UI | 原子化布局、玻璃态主题、高精度动效 |
| 📊 数据可视化层 | Recharts（商家端）+ ECharts（厂商端） | 流量看板、漏斗图、履约趋势 |
| 🔌 后端 API 层 | **Python / FastAPI**（`api/` 代理服务）+ **Java / Spring Boot 3.x**（厂商端生产 REST） | 高性能异步代理 + 企业级 REST Server |
